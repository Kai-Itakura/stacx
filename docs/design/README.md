# デザイン参照

採用した見た目のスクリーンショット（STAR 中心モデル / モノクローム方向）。

**トークンの値は `packages/web/app/app.css` が正典**で、ここには置かない。
状態色は 2 つだけ（未解決 = 琥珀 / 完成 = グリーン）で、同じテーマ内では明度と彩度を
共有し色相だけで分ける（ダーク 0.82 / 0.14、ライト 0.545 / 0.11）。新しい状態を足すときは
色を増やさず、形で区別する。
